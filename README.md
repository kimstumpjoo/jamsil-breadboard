# jamsil-breadboard

논리설계실험용 브레드보드 편집기이자 정지 상태 논리 시뮬레이터입니다. HTML 파일 하나로 동작하고, 설치나 인터넷 연결이 필요 없습니다.

## 받기와 실행

1. [Releases](../../releases)에서 최신 버전의 `index.html`을 내려받습니다. 저장소의 `index.html`을 열고 **Download raw file**을 눌러도 됩니다.
2. 파일을 더블클릭해 브라우저로 엽니다. Chrome이나 Edge를 권장합니다.
3. 시뮬레이션은 새 창으로 열립니다. 창이 뜨지 않으면 브라우저에서 이 파일의 팝업을 허용하세요.

## 편집기 사용법

| 키 | 도구 | 동작 |
|---|---|---|
| `V` | 선택·확인 | 구멍을 클릭하면 전기적으로 이어진 구멍이 모두 표시됩니다. 부품이나 선을 클릭하면 정보가 나옵니다. |
| `W` | 배선 | 두 구멍(또는 바인딩 포스트)을 차례로 클릭합니다. |
| `P` | 부품 | 왼쪽 목록에서 부품을 고른 뒤 1번 핀 위치를 클릭합니다. `R`로 방향을 바꿉니다. |
| `D` | 삭제 | 부품이나 선을 클릭해 지웁니다. |

- 되돌리기는 `Ctrl+Z`, 다시 실행은 `Ctrl+Y`, 핀 이름 표시 전환은 `N`입니다.
- 2핀 소자는 처음 클릭한 쪽이 1번 핀입니다. LED는 애노드(+), 전해 커패시터는 +, 다이오드는 애노드가 1번입니다.
- `점검` 탭은 전원 단락, IC 전원 미연결, 한 구멍에 여러 다리를 꽂은 경우 등 배선 규칙 위반을 표시합니다.
- 설계는 `저장(JSON)`으로 파일에 저장하고 `열기`로 불러옵니다. 그림은 `그림 저장(PNG)`으로 저장합니다.

## 시뮬레이션

- 편집기 상단의 **시뮬레이션 창 열기**를 누르면 읽기 전용 창이 열립니다. 편집기에서 설계를 바꾸면 시뮬레이션 창에 자동으로 반영됩니다.
- 입력은 **바인딩 포스트(전원 공급기)**로 넣습니다. 기본 설정은 빨강 VCC, 초록·파랑 입력, 검정 GND이며 `보드 설정` 탭에서 바꿀 수 있습니다. 시뮬레이션 창 왼쪽에서 각 입력 포스트의 전압을 정합니다. 보드 위 포스트를 클릭해도 0V와 5V가 전환됩니다.
- 전압은 논리 계열 기준으로 판정합니다.
  - 74LS: 0.8V 이하는 0, 2.0V 이상은 1
  - 74HC(5V): 1.5V 이하는 0, 3.5V 이상은 1
  - 그 사이 전압은 X(불확정)로 처리합니다.
- 넷 색상은 1이 빨강, 0이 파랑, 저항을 거친 약한 값이 연한 색, 모름·충돌이 보라입니다.
- `경고` 탭은 다음을 표시합니다: 출력 충돌, IC 전원 없음, 직렬 저항 없는 LED, 떠 있는 입력, 전원 범위를 넘는 입력 전압, 발진 루프, 래치 유지 상태.
- 모든 전원 채널의 − 단자는 GND 포스트와 공통이라고 가정합니다.

## 새 부품 등록

`부품 추가` 탭에서 핀 수, 핀 이름, 동작 정의를 입력합니다. 동작 정의는 출력 핀마다 식을 한 줄씩 씁니다.

```
# 메모는 줄 맨 앞에 "# "으로 씁니다
let s = A ^ B
SUM = s ^ CIN
#3 = !(#1 & #2)
```

- 연산: `!` NOT, `&` AND, `|` OR, `^` XOR, `조건 ? 참 : 거짓`, 괄호
- 상수: `0`, `1`, `X`(모름)
- 핀 이름이 숫자이거나 괄호를 포함하면 `#번호`로 씁니다.

## 주의

- 보드 구조(스트립 행 수, 레일 끊김 여부)는 기본값이 추정치입니다. 실제 보드와 다르면 `보드 설정`에서 맞추세요.
- 기본 부품의 핀 이름과 동작은 표준 74 시리즈 기준입니다. 실험 매뉴얼과 데이터시트로 반드시 확인하세요.
- 시뮬레이션은 정지 상태의 논리값만 계산합니다. 시간 지연, 클럭 동작, 전압·전류, 접촉 불량, 칩 불량은 반영하지 않습니다. 플립플롭·카운터·555의 출력은 X로 표시합니다. 시뮬레이션을 통과해도 실제 회로가 동작한다는 보장은 없습니다.
- 작업 내용은 브라우저에 자동 저장되지만, 브라우저나 파일 위치가 바뀌면 보이지 않을 수 있습니다. 중요한 설계는 JSON으로 저장해 두세요.
